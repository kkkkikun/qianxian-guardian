## 不可用项的诚实说明

`task.md` 第 6/10 条依赖 **Matrix 群聊 + 常驻 bot 进程**——
这是 Python guardian 原型的能力。script-app 形态（App Hub 商店应用）**不接入 Matrix 房间**，
也没有后台定时器，因此这两条不适用。

**这不是"没做"，是"形态不同"**。同一套业务设计（分诊/状态机/回执/冲突）在
`app/guardian/` 中**仍以 Python 实现并通过 G1–G5 六套冒烟（70+ 断言）**，
作为场外链路证明保留在仓库中（`evidence/regression-20261001.md` 第 4 节、
`app/guardian/`），供评审对照。
