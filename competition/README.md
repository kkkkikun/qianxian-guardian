## 一分钟了解这次参赛

- **比赛**：[GOSIM「Agentic App 黑客松 2026」](https://create.gosim.org/agenticapp26/)——主题「意图，即应用」（The Intent Is the App），要求作品完成真实任务闭环：读状态 → 提议 → 授权 → 执行 → 核验。技术平台 OctoSense，赞助 MiniMax / Kimi。
- **队伍**：Aurora-X
- **作品**：「牵线 · 聚会筹办守护」（qianxian）——一条群消息，长成一个被照顾到收尾的完整活动。
- **场景方向**：日历 × 即时消息联动。
- **核心设计**：**agent 提案，程序校验，人来拍板**。agent 经宿主内核回合只产出 PLAN 单行文本提案，12 个白名单 op 覆盖全部状态变更；数字全由代码从状态机算，模型零参与；抽不到的字段留空写「未抽取到」，绝不编造（no-facts 铁律）。
- **成绩**：初赛 **73/100 入围**（评审版 v0.1.0）；决赛答辩后**未获奖**，决赛榜前三为 80 / 77 / 74——我们与二等奖线只差个位分。逐维度差距分析见 [retrospective.md](retrospective.md)。

## 想说的话

没拿到奖，说不遗憾是假的——74 分的二等奖线，就在我们够得着的地方。
但回头看这二十天：从读懂 23 个上游仓库开始，到把「agent 提案、人拍板」的
信任模型做成 12 个可机器校验的 op；从初赛被指出三个问题，到决赛把 40/40 回归
跑进每次提交的门禁；从自己的 app 里一路修出 5 个上游 PR——
这个过程中的牵线，已经是奖品本身。

比赛结束了，牵线还没有。它现在学会了在 Android 手机上用端侧模型思考。
故事在 [retrospective.md](retrospective.md) 里继续。
